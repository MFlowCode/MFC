# Cylindrical viscous operator: manufactured solutions

One RK3 step of a manufactured velocity field in cylindrical coordinates (x axial, y = r with the axis at r = 0,
z = theta in radians), uniform density and pressure, mu = 1. The viscous rate is measured as
`(q(dt) with viscosity - q(dt) without) / dt`, so every inviscid term cancels, and compared with the exact rate
of the field (`exact_rates.py`, generated by `derive_rates.py` with sympy).

| `--case` | field | checks |
| --- | --- | --- |
| `A3` | `u_x = A (r/R)^2 cos(theta)` | theta divergence; exact `d(rho u_x)/dt = 3 mu A cos(theta)/R^2` at every r (issue #1910) |
| `B3` | `u_theta = A (r + 0.5/r)` (Taylor-Couette) | hoop term `tau_r_theta / r`; exact viscous force zero (rings with r >= 0.5) |
| `C3` | `u_x = A r^3 cos(theta)`, `u_r = A r^2 cos(theta)`, `u_theta = A (r^3 - r^2 sin(theta))` | all components, shear and bulk viscosity, both hoop terms, viscous work |
| `E2` | `u_x = A (r/R)^2`, `u_r = A (r/R)^3` (2D axisymmetric) | radial flow: `u_r/r` in div u and the hoop term `-tau_theta_theta / r` |

```
python3 examples/3D_cyl_viscous_mms/run_mms.py --case A3 -N 32 64 128 -- --no-build
```

The trailing flags are passed to `./mfc.sh run` (use the build flags of your build). The script writes its runs
to `examples/3D_cyl_viscous_mms/runs/` and prints, per grid and component, the max-norm error relative to the
largest exact rate and the distance to the rates of the operator before the fix (`MASTER` in `exact_rates.py`).
Results: `docs/documentation/validation_coordinates.md`.
